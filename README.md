# CAI Demo Workspace

Workspace root for the Cloudera AI demo assets.

Primary project folders:
- `ask-data` for the SQL and analytics assistant flow
- `fraud-ai-assistant` for the fraud-focused assistant and traditional ML workflow

Shared supporting assets:
- `sample/` for generated demo CSV files
- `generate_demo_data.py` for synthetic dataset generation
- `impala_demo_ddl.sql` for Impala table definitions
- `submit_impala_schema.py` for applying the DDL to Impala from a local session
